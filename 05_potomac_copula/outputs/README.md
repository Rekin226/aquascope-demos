# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `daily_discharge.csv` | Daily mean discharge fetched from USGS NWIS for gauge 01646500. |
| `peak_volume_pairs.csv` | Annual (peak cfs, 30-day max volume cfs·day) pairs derived from the daily series. |
| `copula_comparison.csv` | AIC ranking of four copula families — family, θ, Kendall τ, Spearman ρ, log-lik, AIC. |
| `joint_return_periods.csv` | Joint return-period table for combinations of peak and volume thresholds. |
| `copula_scatter.png` | Peak vs 30-day volume on pseudo-observation coordinates with best-fit copula density contours. |
| `family_aic_bars.png` | AIC bar chart across the four families. |
