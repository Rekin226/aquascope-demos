# Outputs

Artifacts generated by `notebook.ipynb`. Each figure is provided in both PNG (300 dpi raster, web/LinkedIn-ready) and PDF (vector, publication-ready).

| File | What it is |
|------|------------|
| `flood_frequency_curve.{png,pdf}` | LP3 fit with 90 % CI band; GEV (L-moments) overlaid for comparison; 1936 historic peak annotated. Return level vs. return period (log-x). |
| `fema_comparison.{png,pdf}` | LP3 estimates side-by-side with FEMA FIS 2010 Table 4 quantiles, with per-return-period Δ% and a shaded ±10 % tolerance band. LP3 90 % CI shown as error bars. |
| `qq_diagnostic.{png,pdf}` | LP3 goodness-of-fit Q-Q (log10 space) and P-P plots with 1:1 reference, Cunnane plotting positions. |
| `return_periods.csv` | Numeric table — return period, LP3 estimate, GEV estimate, lower/upper CI for return periods 2, 5, 10, 25, 50, 100, 200, 500. |
| `annual_peaks.csv` | Cleaned annual-peak series fetched from USGS NWIS for gauge 01646500. Cached for offline re-runs. |
