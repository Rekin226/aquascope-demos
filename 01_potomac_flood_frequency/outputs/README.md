# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `flood_frequency_curve.png` | LP3 fit with 90 % CI band; GEV overlaid for comparison. Return level vs. return period (log-x). |
| `qq_diagnostic.png` | Q-Q and probability plots for the LP3 fit, showing residual structure. |
| `return_periods.csv` | Numeric table — return period, LP3 estimate, GEV estimate, lower/upper CI for return periods 2, 5, 10, 25, 50, 100, 200, 500. |
| `annual_peaks.csv` | Cleaned annual-peak series fetched from USGS NWIS for gauge 01646500. Cached for offline re-runs. |
