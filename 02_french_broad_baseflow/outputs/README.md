# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `daily_discharge.csv` | Cleaned daily mean discharge fetched from USGS NWIS for gauge 03451500. Cached for offline re-runs. |
| `baseflow_components.csv` | Daily total / Lyne-Hollick baseflow / Eckhardt baseflow / quickflow. |
| `baseflow_separation.png` | Three-panel plot — total flow with each baseflow estimator overlaid for a representative 3-year window. BFI annotated. |
| `signatures.csv` | The 22 hydrological signatures from `compute_all_signatures` (one row). |
| `signatures_dashboard.png` | Flow-duration curve plus summary panel of the headline signatures. |
