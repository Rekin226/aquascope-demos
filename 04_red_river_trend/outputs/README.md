# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `annual_peaks.csv` | Cleaned annual peak series fetched from USGS NWIS for gauge 05082500. Cached for offline re-runs. |
| `trend_summary.csv` | One-row summary — Mann-Kendall τ, Z, p-value, Sen's slope, intercept; Pettitt change-point year and p-value. |
| `trend_plot.png` | Annual peaks with Sen's slope, Pettitt change-point marker, and pre/post means annotated. |
| `changepoint_plot.png` | Pettitt U_k statistic vs year with significance threshold. |
