# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `tamsui_samples.csv` | Raw water quality samples for the Tamsui basin, fetched from Taiwan MOENV. Cached for offline re-runs. |
| `ai_recommendations.csv` | Top-5 AquaScope methodology recommendations for a Tamsui WQ dataset profile, with score and rationale. |
| `rpi_by_station_date.csv` | Taiwan River Pollution Index (RPI) per station-date with score breakdown and category. |
| `rpi_distribution.png` | Bar chart of the four official Taiwan EPA pollution categories across the dataset. |
| `rpi_by_station.png` | Mean RPI per station, sorted to show the upstream-to-estuary gradient. |
| `do_trend.png` | Dissolved oxygen time series at the most-sampled station with Sen's slope and MK p-value annotated. |
