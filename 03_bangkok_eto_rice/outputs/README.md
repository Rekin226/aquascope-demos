# Outputs

Artifacts generated by `notebook.ipynb`.

| File | What it is |
|------|------------|
| `bangkok_weather.csv` | Daily Tmin / Tmax / RHmin / RHmax / wind / shortwave radiation / precipitation from Open-Meteo for the rice wet-season window. Cached for offline re-runs. |
| `daily_eto.csv` | FAO-56 Penman-Monteith ET₀ (mm/day) for each day in the wet-season window. |
| `crop_water_balance.csv` | Daily Kc, ETc, precipitation, soil moisture (mm), irrigation events (mm) for the 120-day rice cycle. |
| `eto_seasonal.png` | Daily ET₀ over the rice growing season with Kc curve and ETc overlaid. |
| `water_balance.png` | Soil-moisture trajectory with auto-irrigation events and deficit periods marked. |
